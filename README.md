# Naruto TCG Discord Bot

Discord bot for the **Naruto TCG Community Indonesia**.

## Features

- Managed Discord embeds
- MongoDB-backed message templates
- Slash commands
- Role-based permissions
- Modular architecture for future expansion

## Tech Stack

- Python 3.13
- discord.py
- MongoDB
- Docker
- Docker Compose

## Run Locally

```bash
python -m bot.main
